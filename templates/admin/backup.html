Как это работает
  • Каждые 5 минут сервер автоматически загружает снимок БД в uploads/backup.json в Supabase.
  • При следующем деплое (push) Render перезапустит приложение с пустой SQLite — данные восстановятся из этого снимка.
  • Если Supabase недоступен — используется seed_data.json из репозитория (как резервный вариант).
  • Файлы (картинки, PDF) лежат отдельно в Supabase Storage и не слетают при деплое.
